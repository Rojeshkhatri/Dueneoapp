    15→    15→# 1. Executive Summary
    16→    16→
    17→    17→Dueneo is a focused browser-first platform for practical tools and lightweight classic games. The product is built around three promises:
    18→    18→
    19→    19→1. **Useful:** Each page solves a real user problem immediately.
    20→    20→2. **Private:** Tool processing happens locally in the user's browser wherever technically possible.
    21→    21→3. **Fast:** Pages are static, lightweight, mobile-first, and built for search engines and users.
    22→    22→
    23→    23→Dueneo is not a heavy SaaS. It is not a login-based application. It is not a graphics-heavy gaming portal. It is a clean, durable, SEO-first utility platform containing 100 high-value tools and 15 classic games that can run from a static site.
    24→    24→
    25→    25→The whole system is designed so humans and AI coding agents can work safely from the same document. Codex can implement tools and tests. Hermes or OpenClaw can research SEO improvements and generate pull requests. GitHub Actions validates every change. Cloudflare Pages deploys production.

    29→    29→# 2. Non-Negotiable Product Principles
    30→    30→
    31→    31→## 2.1 Browser-first
    32→    32→
    33→    33→Every tool must run in the browser unless this Bible explicitly approves another architecture. The default answer to new feature ideas is:
    34→    34→
    35→    35→> Can this run locally in the browser with no backend and no upload?
    36→    36→
    37→    37→If the answer is no, the feature is excluded from the current Dueneo scope.
    38→    38→
    39→    39→## 2.2 Privacy-first
    40→    40→
    41→    41→For tools that handle files, passwords, invoices, text, JSON, images, or PDFs:
    42→    42→
    43→    43→- Do not upload the user's input.
    44→    44→- Do not log tool input to analytics.
    45→    45→- Do not store personal data unless the user chooses local save.
    46→    46→- Do not send generated passwords, invoices, JSON, text, or files to any third party.
    47→    47→- Show a short privacy note near the tool area.
    48→    48→
    49→    49→Standard privacy note:
    50→    50→
    51→    51→> Your file/data is processed locally in your browser. It is not uploaded to Dueneo.
    52→    52→
    53→    53→For pages that include ads or analytics, the privacy policy must disclose ad/analytics scripts separately. The local-processing promise applies to the tool's input and output.
    54→    54→
    55→    55→## 2.3 One design system
    56→    56→
    57→    57→All pages must look and feel like Dueneo:
    58→    58→
    59→    59→- Same header.
    60→    60→- Same footer.
    61→    61→- Same search.
    62→    62→- Same spacing.
    63→    63→- Same card style.
    64→    64→- Same ad locations.
    65→    65→- Same FAQ style.
    66→    66→- Same related-tool style.
    67→    67→
    68→    68→Only the inner tool/game logic changes.
    69→    69→
    70→    70→## 2.4 Production quality from the first public release
    71→    71→
    72→    72→Every published page must have:
    73→    73→
    74→    74→- Working tool/game.
    75→    75→- Useful surrounding content.
    76→    76→- Unique metadata.
    77→    77→- Canonical URL.
    78→    78→- Structured data where appropriate.
    79→    79→- Related links.
    80→    80→- Mobile layout.
    81→    81→- Accessibility basics.
    82→    82→- Error states.
    83→    83→- Performance budget.
    84→    84→- No broken internal links.
    85→    85→
    86→    86→## 2.5 SEO is product work
    87→    87→
    88→    88→SEO is not a separate trick. SEO means improving the website itself:
    89→    89→
    90→    90→- Better titles.
    91→    91→- Better descriptions.
    92→    92→- Better page content.
    93→    93→- Better internal links.
    94→    94→- Better structured data.
    95→    95→- Better speed.
    96→    96→- Better UX.
    97→    97→- Better crawlability.
    98→    98→
    99→    99→AI agents may help with SEO, but they must change the source code through pull requests, not through invisible off-site edits.

   136→   136→# 4. Domain and URL Strategy
   137→   137→
   138→   138→Use the root domain for the tools brand:
   139→   139→
   140→   140→```text
   141→   141→dueneo.com/
   142→   142→dueneo.com/image-compressor/
   143→   143→dueneo.com/pdf-merge/
   144→   144→dueneo.com/json-formatter/
   145→   145→dueneo.com/invoice-generator/
   146→   146→dueneo.com/games/sudoku/
   147→   147→```
   148→   148→
   149→   149→Do not hide primary tools under deep paths such as `/tools/image/image-compressor/`. Short root-level URLs are easier to remember, easier to share, and cleaner in search results.
   150→   150→
   151→   151→## 4.1 URL rules
   152→   152→
   153→   153→Good:
   154→   154→
   155→   155→```text
   156→   156→/image-compressor/
   157→   157→/pdf-merge/
   158→   158→/json-formatter/
   159→   159→/games/sudoku/
   160→   160→```
   161→   161→
   162→   162→Bad:
   163→   163→
   164→   164→```text
   165→   165→/tool?id=123
   166→   166→/tools/all/imagecompressor
   167→   167→/image_compressor
   168→   168→/app/tools/free-online-image-compressor-tool
   169→   169→```
   170→   170→
   171→   171→## 4.2 Trailing slash
   172→   172→
   173→   173→Use one canonical style everywhere. Recommended:
   174→   174→
   175→   175→```text
   176→   176→/image-compressor/
   177→   177→```
   178→   178→
   179→   179→Redirect non-trailing slash to trailing slash or configure the framework to output one consistent canonical URL.

   624→   624→
   625→   625→The ad system must not hardcode AdSense or Media.net directly into pages. Use a network-agnostic component:
   626→   626→
   627→   627→```tsx
   628→   628→<AdSlot
   629→   629→  id="tool-after-main"
   630→   630→  placement="after-tool"
   631→   631→  category="image"
   632→   632→  preferredNetwork="adsense"
   633→   633→/>
   634→   634→```
   635→   635→
   636→   636→The component decides:
   637→   637→
   638→   638→- Whether ads are enabled.
   639→   639→- Which network to use.
   640→   640→- Which placement is allowed.
   641→   641→- Whether the page is excluded.
   642→   642→- Whether the user has consent requirements in their region.
   643→   643→
   644→   644→Ad slots reserve height to prevent layout shift.

   788→   788→# 10. Browser-Only Engineering Standards
   789→   789→
   790→   790→## 10.1 Data handling
   791→   791→
   792→   792→Tool input must remain in memory, localStorage, IndexedDB, or downloaded output unless the user explicitly exports it.
   793→   793→
   794→   794→Sensitive tools must avoid localStorage by default:
   795→   795→
   796→   796→- Password Generator.
   797→   797→- Password Strength Checker.
   798→   798→- JWT Decoder.
   799→   799→- Hash tools.
   800→   800→- Invoice Generator unless user enables local save.
   801→   801→
   802→   802→## 10.2 Web Workers
   803→   803→
   804→   804→Use Web Workers for:
   805→   805→
   806→   806→- Image compression.
   807→   807→- Large image conversion.
   808→   808→- PDF merging/splitting.
   809→   809→- PDF rendering.
   810→   810→- Large text diff.
   811→   811→- Large CSV/Excel conversion.
   812→   812→
   813→   813→## 10.3 Lazy loading
   814→   814→
   815→   815→Heavy libraries load only after user intent:
   816→   816→
   817→   817→```text
   818→   818→User opens page: no heavy PDF/image library yet.
   819→   819→User selects file: load tool library.
   820→   820→```
   821→   821→
   822→   822→## 10.4 Memory safety
   823→   823→
   824→   824→File tools must:
   825→   825→
   826→   826→- Show file size before processing.
   827→   827→- Reject unreasonable file sizes with friendly message.
   828→   828→- Allow cancellation where feasible.
   829→   829→- Release object URLs after use.
   830→   830→- Avoid keeping multiple large copies of files in memory.
   831→   831→
   832→   832→## 10.5 Browser compatibility
   833→   833→
   834→   834→Support latest stable versions of:
   835→   835→
   836→   836→- Chrome.
   837→   837→- Edge.
   838→   838→- Firefox.
   839→   839→- Safari.
   840→   840→- Mobile Safari.
   841→   841→- Chrome Android.
   842→   842→
   843→   843→For unsupported browser APIs, show fallback guidance.

   847→   847→# 11. SEO Strategy
   848→   848→
   849→   849→## 11.1 SEO goal
   850→   850→
   851→   851→Each tool and game page should target one clear search intent. Dueneo should not rely on one homepage ranking. Every tool page is a search landing page.
   852→   852→
   853→   853→## 11.2 Google SEO principles
   854→   854→
   855→   855→Google SEO starts with making pages useful, crawlable, understandable, and technically sound. Dueneo follows these rules:
   856→   856→
   857→   857→- Clear descriptive page titles.
   858→   858→- Unique meta descriptions.
   859→   859→- Helpful content around the tool.
   860→   860→- Static HTML for crawlers.
   861→   861→- Valid canonical URLs.
   862→   862→- Structured data where appropriate.
   863→   863→- Useful internal links.
   864→   864→- Fast loading.
   865→   865→- Mobile-friendly layouts.
   866→   866→- No thin pages.
   867→   867→
   868→   868→## 11.3 Bing SEO principles
   869→   869→
   870→   870→Bing optimization is not separate from good SEO, but Dueneo should explicitly support Bing:
   871→   871→
   872→   872→- Submit sitemap to Bing Webmaster Tools.
   873→   873→- Use IndexNow for changed URLs.
   874→   874→- Maintain clean XML sitemaps.
   875→   875→- Use structured data.
   876→   876→- Use descriptive titles and content.
   877→   877→- Avoid spammy generated pages.
   878→   878→
   879→   879→## 11.4 IndexNow
   880→   880→
   881→   881→Dueneo uses IndexNow only for URLs that are added, updated, or deleted. The script should read changed pages from the build or Git diff and submit those URLs.
   882→   882→
   883→   883→Example request shape:
   884→   884→
   885→   885→```json
   886→   886→{
   887→   887→  "host": "dueneo.com",
   888→   888→  "key": "INDEXNOW_KEY",
   889→   889→  "keyLocation": "https://dueneo.com/INDEXNOW_KEY.txt",
   890→   890→  "urlList": [
   891→   891→    "https://dueneo.com/image-compressor/",
   892→   892→    "https://dueneo.com/pdf-merge/"
   893→   893→  ]
   894→   894→}
   895→   895→```
   896→   896→
   897→   897→IndexNow submission is a discovery signal, not a guarantee of indexing.

  1049→  1049→
  1050→  1050→## 12.1 Ad philosophy
  1051→  1051→
  1052→  1052→Dueneo uses simple, non-obstructive ads. The page must remain useful even if ads fail to load.
  1053→  1053→
  1054→  1054→Maximum default:
  1055→  1055→
  1056→  1056→```text
  1057→  1057→Ad Slot 1: after tool/game

  1061→  1061→## 12.2 AdSense
  1062→  1062→
  1063→  1063→AdSense is the primary starting ad network.
  1064→  1064→
  1065→  1065→Rules:
  1066→  1066→
  1067→  1067→- Do not place ads near copy/download/play buttons.
  1068→  1068→- Do not label ads misleadingly.
  1069→  1069→- Use `Advertisement` or `Sponsored` only if a label is needed.
  1070→  1070→- Do not use popups or forced interstitials.
  1071→  1071→- Reserve ad slot space to reduce layout shift.
  1072→  1072→- Exclude sensitive pages if needed.
  1073→  1073→
  1074→  1074→## 12.3 Media.net
  1075→  1075→
  1076→  1076→Media.net is included as a controlled monetization network, not hardcoded into every page.
  1077→  1077→
  1078→  1078→Testing plan:
  1079→  1079→
  1080→  1080→```text
  1081→  1081→Image tools: compare AdSense vs Media.net on second slot.
  1082→  1082→PDF tools: compare AdSense vs Media.net on second slot.
  1083→  1083→Business/finance tools: compare both networks carefully.
  1084→  1084→Games: test only after UX is stable.
  1085→  1085→```
  1086→  1086→
  1087→  1087→Do not place both networks so densely that ads overwhelm content.
  1088→  1088→
  1089→  1089→## 12.4 Ad rules by page type
  1090→  1090→
  1091→  1091→```text
  1092→  1092→Tool pages: up to 2 ads.
  1093→  1093→Game pages: up to 2 ads, never inside game board.
  1094→  1094→Legal pages: no ads.
  1095→  1095→Contact page: no ads.
  1096→  1096→Privacy page: no ads.
  1097→  1097→Homepage: 0-1 ad only after content, optional.
  1098→  1098→Category pages: 0-1 ad, optional.
  1099→  1099→```
